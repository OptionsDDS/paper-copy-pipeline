# Fixed-choice layout checker

This is a separate stage-2/3 verification harness. It reads the boxer's page records and PDF, asks a local vision model fixed-choice questions, and writes an ID-only decision overlay. It never edits `copy_paper.py`, the boxer, input records, PDF text, or `copy.md`. It does not claim that a model flag repairs a paper.

All CPU commands use `/usr/bin/python3 -I` and the standard library. The renderer calls `pdftoppm`; geometry and source-line grouping reuse the vendored reader and the functions in `tools/export_lines.py`, without running the copy program. The sole dependency exception is GPU inference in the supplied vLLM environment.

## Build and run

From the worktree:

```bash
/usr/bin/python3 -I tools/checker/build_questions.py RECORDS PAPER.pdf BUNDLE
/usr/bin/python3 -I tools/checker/run_model.py BUNDLE PREFLIGHT --dry-run
```

`RECORDS` must contain all `page-NN.json` files after rules 6–7. `BUNDLE` must be empty and separate from the source. The builder stores every page once at 110 dpi, plus boxes, source run IDs, physical lines, and source hashes in `bundle.json`. Individual outlined images and crops are rendered in memory. A changed image, question or bundle invalidates old answers. `--block-edges-only` omits internal line edges when intentionally measuring only block order.

The requested benchmark can be rebuilt with:

```bash
/usr/bin/python3 -I tools/checker/prepare_benchmark.py \
  --fault-pool /mnt/ai/projects/optionsdds/trials/copy-lanes/repo/fault-pool.json \
  --pdf-maps tools/pdfs-ac.json tools/pdfs-ad.json tools/pdfs-ae.json tools/pdfs-af.json \
  --records-roots /mnt/ai/projects/optionsdds/trials/copy-lanes/r26copies-N \
                  /mnt/ai/projects/optionsdds/trials/copy-lanes/r26copies-KAF \
  --out /mnt/ai/projects/optionsdds/trials/copy-lanes/out-checker/benchmark-new \
  --regenerate-missing --workers 3
```

Selection uses only audited zero-MAJOR papers for negatives. It does not treat previously failing papers as clean because a later text search says “fixed.” If the requested sets have fewer negatives, it retains the available papers and reports the shortfall. `--extra-negative PAPER` accepts an explicitly selected audited negative from another set; also supply its PDF map. The normal code contains no paper-specific selection or repair rules.

On this checkout the requested round-26 folders lack AC–AF inputs, so the delivered benchmark uses records regenerated by the unchanged local boxer. They are identified as such in the manifest; they are not represented as the historical audited copies. `main_text` is used as recorded, including the boxer's abstract/body conventions. Copies and source elements may have different postprocessing, so historic copy faults are provisional labels for this stage.

The supervisor can run the delivered bundle set on the GPU with:

```bash
/mnt/ai/projects/optionsdds/trials/vlm-trial/envs/monkeyocrv2-vllm-0.25.1/bin/python -I \
  tools/checker/run_model.py \
  /mnt/ai/projects/optionsdds/trials/copy-lanes/out-checker/benchmark/manifest.json \
  /mnt/ai/projects/optionsdds/trials/copy-lanes/out-checker/answers \
  --model /mnt/ai/models/AI_MODELS/huggingface/Qwen__Qwen3-VL-8B-Instruct
```

Use `--resume` with the same model/settings after interruption. `--max-questions`, `--types Q1 Q2`, `--batch-size`, `--gpu-memory-utilization` and `--tensor-parallel-size` permit a pilot or different hardware allocation. Pilot/partial results remain incomplete in the scorer. Keep dry-run and inference output directories separate. The model argument must be a local directory. Downloading and telemetry are disabled before vLLM is imported; compiler caches stay under the response directory. The runner uses `LLM.chat` as in the supplied working script, with four-image support and `StructuredOutputsParams(json=...)` per question. It fails if structured outputs are unavailable; there is no unconstrained fallback. The actual GPU installation/model load must still be tested by the supervisor.

Apply and score all papers:

```bash
/usr/bin/python3 -I tools/checker/apply_decisions.py \
  /mnt/ai/projects/optionsdds/trials/copy-lanes/out-checker/benchmark/manifest.json \
  /mnt/ai/projects/optionsdds/trials/copy-lanes/out-checker/answers \
  /mnt/ai/projects/optionsdds/trials/copy-lanes/out-checker/overlays
/usr/bin/python3 -I tools/checker/score.py \
  /mnt/ai/projects/optionsdds/trials/copy-lanes/out-checker/benchmark/manifest.json \
  /mnt/ai/projects/optionsdds/trials/copy-lanes/out-checker/answers \
  /mnt/ai/projects/optionsdds/trials/copy-lanes/out-checker/scores.json
```

For one paper, `apply_decisions.py BUNDLE ANSWERS.jsonl OVERLAY.json` works too. `--threshold` defaults to 0.85 in both the applier and scorer; use the same value. Model-reported confidence is not calibrated probability. No threshold has been validated on this corpus.

## Question and decision contract

| Type | Evidence and fixed choices | Result |
|---|---|---|
| Q1 | Full page, one red large box; nine requested classes | Confident classes go into the overlay. A mismatch is a flag. Refining a broad source other/aside or furniture class to a compatible subtype is not a false alarm. |
| Q2 | A's last two lines, B's first two lines, and their full pages; yes/no | Every body block edge, including cross-page edges, plus internal body line edges. “No” rejects the edge; no replacement order is guessed. |
| Q3 | Every page with blue body boxes, even an empty page; yes with outlines/no | Missing body regions are flagged with integer full-page coordinates in 0–1000. No text is invented. |
| Q4 | Main-header candidates outlined; ten requested subtypes | Known source title/author/abstract subtypes can be checked. An unknown source subtype is an annotation, not automatically an error. |
| Q5 | Full page with labeled float/caption candidates; yes/no plus fixed affected IDs | Handles orphan captions, unpaired graphics, captions embedded in tables, and missing detections (`unboxed` with outlines). |

The model sees no audit descriptions, truth labels, existing expected answers, or paper selection labels. Only the fixed JSON answer fields are accepted. Arbitrary prose, additional keys, unknown/repeated IDs, duplicate JSON keys, invalid coordinates, non-finite confidence, and truncated output are rejected. All low-confidence choices become flags, including low-confidence agreement. Unanswered and invalid responses become operational review flags; they are never counted as successful detections or clean negatives. Body membership changes require order review. A Q4 subtype cannot overrule a contradictory Q1 class.

The overlay preserves the original order and records rejected edges. It intentionally has `ready_for_automatic_copy: false`: the yes/no question design provides no replacement order or missing text, and copying uncertain corrections back into the pipeline would be unsafe. This is a reviewable decision applier, not a Markdown writer.

## Scoring without invented truth

`truth.json` retains the selected papers' audit fault IDs, original page fields, causes, historical statuses, and exclusions. `score.py` reports:

- Exact fault recall only for faults manually associated with `question_ids`, `truth_status: "verified"`, and the matching current `bundle_sha256`. The reviewer must check these against this input's page records/PDF. Supply that edited truth with `--truth PATH`.
- A separately named **historical page/type screening** proxy when a supported, not-already-fixed fault has explicit pages. An alarm on a different page or unrelated question type cannot catch it. Several alarms do not count one fault more than once. This proxy can over-credit an unrelated alarm on the same page/type; it is not exact fault recall.
- False alarms on audited negatives, per question type and per paper, with uncertainty included and confident disagreements also shown separately. A partially answered paper never receives a final clean-paper score. Runtime failures and missing answers are listed separately.
- Explicit exclusions for absent audit pages, already-fixed faults, unsupported causes, and missing candidate questions. These do not become wildcard matches. No inference means `null` recall/FPR, not zero errors.

This harness checks sorting, adjacency, coverage and caption pairing. It is not a value/OCR/table-cell accuracy checker. Internal line edges help with interleaving, but do not establish within-line reading order. A source image-only page gets Q3/Q5, without invented text/header boxes. Exact same-class title/byline corruption, table values, glyph substitutions and unsupported historic faults need separate checks or adjudication.

## Tests and artifacts

```bash
/usr/bin/python3 -I tools/checker/run_tests.py \
  /mnt/ai/projects/optionsdds/trials/copy-lanes/out-checker/validation/suite --workers 4
```

This executes every `tools/test_*.py` in its own `/usr/bin/python3 -I -m unittest discover` process. Explicit discovery supplies sibling fixtures and runs the existing `test_regions.load_tests` hook. CPU tests cover real Poppler pixels, rotated geometry, class/edge application, malformed/stale answers, missing detections, exact versus proxy scoring, and the runner API with a CPU fake of vLLM. They do not claim a real GPU run.

The output directory contains the benchmark/manifest/truth, preflight, representative page previews, pending overlays/scores, validation evidence, and REPORT.md. The benchmark builder enforces a configurable byte ceiling (default 2 GB), leaving room below the job's 2.5 GB total limit. Completed benchmark runs and previews use approximately 150 MB here; no per-question images are stored.
